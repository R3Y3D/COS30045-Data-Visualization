About The Project

Demonstrating core web development standards, responsive design, and DOM manipulation.

Project Overview

The Appliance Energy Consumption Website was developed as an educational web design project demonstrating core front-end engineering fundamentals: semantic HTML structure, responsive CSS layout, and client-side JavaScript execution.

The site focuses on the Australian energy market context, educating consumers on electricity tariff structures, energy efficiency labels, and power consumption calculations.

📌 Technical Highlights

  • Clean semantic HTML5 structure
  • Consistent brand styling via CSS variables
  • Vanilla JavaScript client-side calculator
  • Accessible FAQ accordion menu
  • Fully responsive design across viewports

Generative AI Disclosure & Acknowledgement

In accordance with project guidelines, this website was built with assistance from Generative AI (Gemini). AI was utilized as an AI coding collaborator to assist with:

  • JavaScript DOM event handling, accordion logic, and calculator input validation
