About The Project

Our Mission

The Appliance Energy Consumption Project was developed to empower consumers with clear data on household power consumption. Electricity rates continue to fluctuate, making energy literacy crucial for budgeting and sustainability.

Through simple interactive tools and comparative data, this site helps users quantify the real financial cost of their everyday electrical devices.

⚡ Key Goals

  • Demystify electrical power units (Watts vs. kWh).
  • Provide real-time interactive energy calculators.
  • Promote energy-efficient purchasing decisions.
  • Demonstrate clean web development architecture.

Web Development Standards Demonstrated

This website was constructed adhering to core web development practices and clean project organization:

Semantic HTML5

Utilizes clean structure tags (<header>, <nav>, <main>, <section>, <footer>) for improved accessibility and SEO.

CSS Variables & Flex/Grid

Built with modern CSS layouts using Flexbox, CSS Grid, custom color variables, and media queries for responsive mobile scaling.

Dynamic JavaScript

Employs modular DOM manipulation, dynamic class toggling, event handling, and calculation formulas without heavy external libraries.
